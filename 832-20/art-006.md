# Art. 6 c) Procédure
1 A moins que le cas n'ait déjà été soumis à un organisme de conciliation prévu par convention, le tribunal arbitral ne peut être saisi sans procédure de conciliation préalable; le président procède, dans ces cas, à une tentative de conciliation en présence d'un représentant de chaque partie; si cette procédure échoue, le président fixe un délai approprié pour introduire l'instance.
2 Lors du jugement, aucun membre ne peut s'abstenir de voter.
3 Pour le surplus, font règle les dispositions du Code de procédure administrative.
