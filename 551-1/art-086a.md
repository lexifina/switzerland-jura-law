# Art. 86a Champ d'application
1 Le présent chapitre règle le traitement des données personnelles effectué par la police cantonale (dénommées ci-après : "les données de police") dans le cadre de ses missions.
2 Il ne s’applique pas aux droits des personnes concernées dans le cadre de procédures pendantes régies par le Code de procédure pénale suisse.
