# Art. 165 3. Maintien du profil scolaire
1 Le profil scolaire de l'élève est déterminé par le niveau suivi dans chacune des disciplines de base et par le groupe de cours à option principaux qu’il fréquente.
2 Lors du passage d'une année scolaire à l'autre, l'élève peut poursuivre les cours des disciplines de base dans les mêmes niveaux s'il obtient une note de promotion suffisante dans chacune des trois disciplines concernées. A défaut, l'élève est transféré dans le niveau inférieur de la discipline pour laquelle il a obtenu une note insuffisante; il peut cependant poursuivre sa formation dans les mêmes niveaux s'il n'a obtenu qu'une seule note insuffisante dans les cours à niveaux et si ses résultats correspondent aux critères fixés par le Département.
