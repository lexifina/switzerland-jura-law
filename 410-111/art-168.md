# Art. 168 5. Orientation dans le cadre des cours à option principaux a) Maintien dans le groupe de cours à option principaux
1 Le maintien de l’élève dans le groupe de cours à option principaux au degré suivant est déterminé par les résultats obtenus dans les disciplines à niveaux et les cours à option principaux pour autant qu’il n’ait pas obtenu de moyenne annuelle insuffisante dans ces derniers. Dans le cas contraire, les résultats obtenus dans le cours à option secondaire et les cours communs sont également pris en compte.
